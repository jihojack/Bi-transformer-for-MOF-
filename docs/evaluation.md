# 평가 프로토콜과 수치 해석

## 1. 내부 시험과 추가 10K

원래 50,000개에서 학습 35,000 / 검증 5,000 / 시험 10,000개를 사용했습니다.
원래 30K의 seed-42 분할을 유지하고 추가 구조를 CO2/CH4 0.5 bar의 공동 층에
따라 배분한 고정 분할입니다. 정확한 ID는 `data/splits/`에 있습니다.
내부 시험은 학습·조율에 사용한 자료와 겹치지 않습니다.

추가 10K는 MOFX-DB 유효 후보 130,044개에서 기존 50,000개 전체를 제외한
80,044개 중 seed 20260727로 비복원 무작위 추출했습니다.
실패에 대비한 예비 순서 500개도 사전 지정했으나 저장된 CPU 평가에서 사용한
예비 표본 수는 0입니다. 추가 10K ID와 원래 50K ID의 교집합은 0개였습니다.

모델과 전처리 파라미터는 동결했습니다. 입력 CSV와 CIF만으로 예측을 완료하고
예측 파일을 저장·해시한 후 별도 정답 CSV를 읽어 지표를 계산하는 프로토콜입니다.
외부 평가 표본으로 scaler, 원소 특성 기준, 금속 배위 기준을 다시 적합하지 않습니다.

두 평가 모두 같은 데이터베이스 계열의 계산값에 대한 평가입니다.
추가 표본 평가를 experimental/OOD 검증으로 부르지 않습니다.

## 2. 평가 지표

조건별 R², RMSE, MAE를 보고합니다. RMSE·MAE 단위는 mmol/g입니다.
Macro는 10개 조건별 지표의 단순 평균입니다.
Pooled/micro는 10개 출력을 모두 펼쳐 계산하므로 다른 수치입니다.

R² = 1 − SSE/SST이므로 대상 세트의 흡착량 분산이 달라지면
RMSE·MAE가 작아져도 R²는 낮아질 수 있습니다. 두 세트 간 지표의
대소만으로 한 세트가 더 쉽거나 모델이 더 좋아졌다고 단정하지 않습니다.

## 3. 융합 비교

동일 내부 시험 10K에서 융합, 구조 보조 헤드, 기술자 보조 헤드를 비교했습니다.
각 MOF를 단위로 1,000회 paired bootstrap을 수행한 저장 결과를 사용합니다.
모든 조건에서 융합 MAE가 낮았고 감소량의 95% 구간 하한이 0보다 컸습니다.

이는 고정 모델·시험 세트에서의 차이를 평가합니다. 별도 학습 시드 변동을
포함하지 않으며, 각 타워와 융합 헤드의 용량·학습 목표가 다릅니다.
동일 용량 독립 단일 타워 또는 단순 평균/선형 stacking 대조군에 대한
실험을 대신하지 않습니다.

## 4. 입력군 제거, 회전 및 구조별 분석

- 입력군 제거는 고정 2,000개 부분집합에서 수행한 post-hoc 분석입니다.
  입력 제거 후 처음부터 재학습한 모델과는 구분합니다.
- FP32 회전 검사는 MOF 200개에서 수행했습니다. 최대 차이 기록은
  0.0010252 mmol/g로 수치 오차가 0인 엄밀한 회전 불변성을 주장하지 않습니다.
- 구조별 분석은 내부 시험 10K에서 각 특성을 2,000개씩 5구간으로 나눕니다.
  오차는 조건별 학습 target scale로 정규화합니다.
  새 구조별 그림의 신뢰구간은 seed 20261025, MOF bootstrap 1,000회입니다.
- 구조 간 상관과 흡착량 분포를 통제한 인과 분석은 아닙니다.

## 5. CPU와 ALCHEMI

CPU 원본 지표는 `results/external/cpu_metrics.json`입니다.
ALCHEMI 지표는 연구자가 제공한 Colab 출력으로부터 별도 JSON에 기록했으며
원본 Colab JSON 파일이 동봉된 것으로 오인하지 않도록 provenance를 표시했습니다.
두 경로는 같은 동결 체크포인트를 사용했으며 평균 차이는 R² 약 2.42e-6,
RMSE 약 6.74e-6, MAE 약 1.55e-6입니다.
이 평가 설정에서의 재현 결과이며 다른 그래프 정의에 대한 동등성을 뜻하지 않습니다.

## 6. 해석 범위

동일 hMOF/MOFX-DB 과제 범위의 예측 성능, 융합 보조 헤드 비교,
수치 재현 및 취약 집단 분석을 제시합니다. 다른 논문의 서로 다른
분할·단위·입력 정보·압력 조건을 맞추지 않은 SOTA 주장은 하지 않습니다.
