# 예측 헤드 비교 그래프

## 추천 그림

`tower_mae_comparison_ko.png`를 보고서 본문에 사용하면 됩니다.
영문판은 `tower_mae_comparison_en`이며 각각 PNG(300 dpi), SVG, PDF를 제공합니다.

`tower_mae_improvement_ci_ko`는 보조 예측 대비 융합 예측의 MAE 감소량과
95% 부트스트랩 신뢰구간을 표시하는 보완 그림입니다.

## 평가 자료와 해석

- 같은 내부 시험 MOF 10,000개에서 계산한 저장된 수치를 사용했습니다.
- 별도로 재학습한 독립 모델이 아니라, 같은 모델 안에서 함께 학습한
  구조 보조 헤드, 기술자 보조 헤드, 융합 헤드의 출력 비교입니다.
- 주 그림의 압력 조건들은 비교하기 쉽게 동일 간격으로 배치했습니다.
  선은 조건 간 시각적 연결이며 압력에 대한 연속 오차 곡선의 추정은 아닙니다.
- CO2와 CH4 패널의 세로축 범위는 서로 다릅니다.
- 신뢰구간은 MOF 단위 부트스트랩 1,000회의 저장 결과를 사용합니다.
  모델 재학습 시드의 변동을 포함하지 않습니다.
- 모든 10개 조건 및 두 보조 헤드 대비 비교 20개에서 MAE 감소량의
  95% 신뢰구간 하한이 0보다 컸습니다. 이는 해당 시험 세트에서의
  개선을 뒷받침하며 동일 용량의 독립 단일 타워 대비 우월성을 입증하는 것은 아닙니다.

원본 폴더:
`results/internal/`

입력 파일은 위 폴더의 `test_metrics_all_towers.csv`와
`extended/paired_tower_mae_bootstrap.csv`의 사본입니다.
두 입력 CSV와 그림 생성 파이썬을 함께 보관하여 재생성할 수 있습니다.

## 시험 세트 구분

원래 50K 데이터의 분할은 학습 35,000, 검증 5,000, 시험 10,000개입니다.
`fixed_split_70_10_20.json`의 세 인덱스 집합을 직접 대조한 결과,
학습/검증, 학습/시험, 검증/시험의 교집합은 각각 0개였습니다.
최종 평가표와 이 비교 그래프는 이 내부 시험 10,000개에 대한 결과입니다.

추가 10K는 같은 MOFX-DB 모집단에서 원래 50,000개 전체를 제외한
80,044개 유효 후보 중 비복원 무작위 추출한 별도 평가군입니다.
실제 `external_10k_predictions.csv`의 10,000개 MOF ID와
원래 학습/검증/시험 ID 전체의 교집합도 0개로 확인했습니다.
따라서 두 평가군 모두 학습 데이터와 겹치지 않습니다.
추가 평가군 역시 동일 데이터베이스에서 왔으므로 다른 데이터베이스 또는
실험 MOF에 대한 분포 밖 검증으로 해석하면 안 됩니다.

## 본문용 캡션

동일한 내부 시험 MOF 10,000개에 대한 기체·압력 조건별 MAE 비교.
융합 예측은 CO2 및 CH4의 모든 평가 조건에서 구조 타워와 전역 기술자
타워의 보조 예측보다 낮은 MAE를 보였다. 각 보조 헤드는 융합 헤드와
함께 학습되었으며, 압력 조건은 시각적 비교를 위해 동일 간격으로 배치하였다.
