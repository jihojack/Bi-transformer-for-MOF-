모델과 데이터 처리

모델 가중치·ONNX 파일을 이 브라우저로 내려받지 않습니다. 서버에서 CIF의 원자 구조와 기술자를 분석하고 예측값만 반환합니다.

표면적·공극률·LCD·PLD는 자동 계산하지 않으므로 해당 CIF와 같은 정의의 수치를 입력하세요. 기존 CIF에 임의의 값을 넣는 경우 입력 민감도 탐색으로 해석해야 합니다.

현재 동결된 원소 표는 Br, C, Cl, Cu, F, H, N, O, V, Zn, Zr을 지원합니다. 부분 점유 구조·여러 구조가 함께 든 CIF는 지원하지 않습니다. 실제 실험 MOF에 대한 정확도는 별도 검증이 필요합니다.
